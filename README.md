# Japan Population Trends

日本の都道府県別人口推移を可視化するシングルページアプリケーション（SPA）。  
RESAS（地域経済分析システム）API のデータを活用し、都道府県ごとの総人口・年齢別人口推移をインタラクティブな折れ線グラフで表示します。

🔗 **デプロイURL**: [https://japan-population-trends-nine.vercel.app/](https://japan-population-trends-nine.vercel.app/)

---

## 💡 設計・実装のこだわり

### 1. パフォーマンス戦略

- 人口動態などの統計データは頻繁に更新されないため、`staleTime: 30分` / `gcTime: 1時間` に設定。
- 不要な再フェッチを防ぎ、タブ切り替えや都道府県の再選択時もキャッシュから瞬時に描画。

### 2. 多様な比較を支える操作性 & 凡例設計

- **地方単位の一括選択**: 単一の都道府県だけでなく、地方同士（例: 関東と近畿）の人口規模や推移をスムーズに比較できるよう、地方ごとの一括選択・解除機能を搭載。
- **アコーディオンによる画面領域の最適化**: 都道府県の一覧は折りたたみ可能にし、選択後はグラフ閲覧に集中できるよう画面スペースを効率化。
- **複数選択時も崩れない固定情報バー**: 多数の都道府県を選択した際にも画面を安定して操作できるよう、各年度の数値をグラフ下の固定エリアに集約。
- **ワンクリックでリセット**: 比較後に素早く次の操作へ移れるよう、フィルター一括解除の `CLEAR` ボタンを配置。

### 3. UI/UX & タイポグラフィ設計

- **ピクセル調・Y2KレトロなUI**
- **視認性とメリハリ**: Geist Pixelフォントを採用し、主役となる数値データを際立たせ、補助ラベルやクレジットは控えめなサイズ（10〜11px）と広めの文字間で配置。
- **モバイルファーストな操作性**: スマートフォン（< 640px）ではグラフカテゴリタブを 2×2 グリッドに切り替え、文字の改行を防ぎつつタップしやすい操作領域を確保。

- **テスト**: Vitest, Testing Library
- **コード品質**: ESLint, Prettier
